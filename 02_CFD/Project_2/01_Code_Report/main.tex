\section{当前版本与旧版本代码的区别}
旧代码位于\texttt{Project\_2\textbackslash old\_code\_and\_data}。

本程序最开始的 old 版本主要目标是先把 MacCormack 格式跑通，因此变量命名和数组组织方式比较直接。程序中大量使用 q1、q2、q3、f1、f2、f3 这类数组名，其中 q1、q2、q3 分别表示守恒量中的密度、动量和总能量。这样的写法和数学推导中的分量形式比较接近，初期实现较快，但当程序加入人工粘性、不同算例、不同 CFL 数和不同差分方向之后，代码的维护和阅读变得非常痛苦，变量数量明显增加，阅读和检查代码时容易混淆不同数组的物理意义。

在 02 版本中，程序的主要改动不是更换数值格式，而是重新整理变量的组织方式。让Code读起来不那么痛苦（尽管变量名和方法 Method 很多）
